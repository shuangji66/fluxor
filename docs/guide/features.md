# 功能特性

Fluxor 提供了一系列实用的富强面板管理和订阅功能，主要包括以下几个核心模块：

---

## 核心功能

### 1. 订阅转换与管理
* **节点自动拉取**：输入机场的 Cl~a~sh / mi鸿蒙 订阅 URL，面板可自动拉取节点列表并在后台保存。
* **双模式切换**：支持“融合模式”（将多个订阅的节点打散并混合使用）与“切换模式”（物理隔离，每次只激活一个订阅）。详见 [订阅工作模式](../config/subscription-modes)。
* **自动定时更新**：支持针对每个订阅设定不同的更新时长。
* **节点前缀**：多订阅并存时可给每个订阅设置前缀，生成的节点名会自动带上该前缀（对应内核 `proxy-provider` 的 `override.additional-prefix`），便于区分节点来源。
* **拉取与容错**：订阅下载采用「直连优先 → 失败则回退临时内核」两阶段策略，两阶段各自限时 15 秒且**不重试**，因此单次更新的最坏耗时是可控的（详见 [架构与设计](./architecture)）。

### 2. 策略组与排序
* **低延迟自动排序**：点击测试延迟后，支持将策略组内的节点按延迟低自动置顶。
* **节点质量自动排序**：选择质量排序后，代理组将支持节点质量评分，评分算法参考自 `MetaCubeXD`，点击评分后，支持将策略组内的节点按质量高分自动置顶。
* **测速并发限制**：全局测速和组测速时，后台自动调度并发为最多 10 个 Workers，防止流量拥堵和 Unix Socket 负载过高崩溃。
* **正则过滤**：支持自定义正则表达式，过滤不想要的节点名称（默认过滤 `(套餐|过期|流量|剩余|订阅|网站|教程)`）。
* **自动断开旧连接**：开关节点后可选自动断开该策略组内的旧连接，让新节点立即生效，无需手动重连。
* **可调阈值与历史**：低/中延迟的颜色阈值（默认 150ms / 300ms）与节点延迟历史色块数量（5–10）均可调整。这些偏好保存在浏览器本地，不写入服务端配置。

### 3. TProxy 透明富强网关模式
* **高灵活性**：支持劫持局域网设备、本机、本机 Docker 桥接网络，灵活性远超 Tun 透明富强模式。
* **绕过列表**：支持设置目的地址绕过和源地址绕过，让特定的物理主机或目标域名直连，不经过富强。详见 [TProxy 透明富强](../config/tproxy)。
* **Docker 默认绕过**：默认将 Docker 桥接网段（`172.17.0.0/16`）排除在劫持范围外，避免容器网络被误劫持。
* **本机富强**：支持通过 nftables 将面板所在主机自身发出的出站流量也进行富强。
* **IPv6 接管（默认关闭）**：单独控制是否随 TProxy 下发 IPv6 家族规则；同时受订阅中心「IPv6 支持」总开关约束（两者都为真才下发，偏好不会被改写）。
* **与 TUN 互斥**：前端先关对侧，后端在下发规则前实时查询内核 `tun.enable` 兜底，多标签页/第三方客户端也无法让两者同时生效。
* **冷启动自愈**：nftables 规则不跨重启存活、而开关状态是持久化的。因此面板每次启动都会**把开关无条件归零并清理可能残留的规则**，避免出现「面板显示已关闭、流量却仍被劫持」的静默错配。

### 4. TUN 模式
* **虚拟网卡接管系统流量**：协议栈可选 `gVisor` / `System` / `Mixed` / `Mips`，并支持自定义设备名与出口网卡。
* **参数与开关分离**：协议栈、设备名、DNS 处理方式与 IPv6 接管保存在 `tun.json`（稀疏，仅存与默认值不同的键），下次开启 TUN 时生效；**TUN 开关不落盘**，内核重启或配置重载后自动关闭，避免开机自动接管网络。
* **默认不接管 IPv6**：多数节点没有 IPv6 出口，接管后原本可直连的 IPv6 目标可能失败；需要时在高级设置里选「自动」。

### 5. 实时活动连接管理
* **瞬时速率计算**：以快照差分法，每秒精准计算出每条活动连接的瞬时网速。
* **连接阻断**：支持断开指定连接，或一键阻断全局连接以强制更新的节点生效。
* **已关闭连接记录**：保留最近 100 条已断开的连接历史。
* **自定义列**：表格列可按需显示/隐藏，偏好保存在浏览器本地。

### 6. 内核状态实时推送
* **无需轮询**：内核运行状态由后端经 SSE（`/core/events`）主动推送，面板静置时不再定时请求状态接口。
* **外部结束也能感知**：内核若崩溃、被 `kill -9` 或 OOM，后端会立即推送「已停止」，面板状态与内核状态始终一致。

## 辅助功能与维护
* **内核日志查看**：流式终端展示运行日志，支持日志级别过滤、暂停自动滚动和实时复制；断线后按 1s→30s 指数退避自动重连。
* **IP 位置探测**：分别获取本机和富强环境下的 IPv4/IPv6，展现其地理位置和运营商归属。归属地查询结果带 10 分钟缓存，避免频繁请求外部接口。
* **DNS 缓存清理**：支持一键清理内核的 DNS 缓存和 FakeIP 映射表，解决常见的解析污染导致国内网站打不开的问题。
* **网络工具**：内置 DNS 查询测试器，可以直接在面板测试域名经由内核解析的结果。
* **配置重载**：支持不重启内核热重载 `config.yaml`，长连接不中断。
* **GEO 数据库更新**：一键更新内核的 GEO 数据库。
* **内核更新**：支持在面板内检查并更新 mi鸿蒙 内核版本（可选 Stable / Alpha 通道）。
* **面板自更新**：支持检查并更新 Fluxor 自身版本。按当前架构优先下载 `fluxor-<架构>.tar.gz` 压缩包并解压提取二进制，压缩包不存在时回退 `fluxor-<架构>` 裸二进制；下载只经「自身代理」与「直连」两条链路（各重试 2 次），全部失败时提示检查代理或网络连接。
* **版本号**：面板版本在内核**编译期注入**，前端经后端接口读取，无需手工同步前端文件。
